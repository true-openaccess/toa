## 附录 A（说明性）上限

把正文各处定的上限汇总在一起，方便实现。本表和正文不一致时，以正文为准。

| 什么 | 上限 | 节 |
|---|---|---|
| 对象名的前缀 | 2 到 8 个字符 | 2.1 |
| 对象名里的哈希 | 恰好 40 位十六进制；64 位保留 | 2.1 |
| 草稿名的标签 | 1 到 40 个字符 | 2.4 |
| 一个文件或目录的名字 | 1 到 64 个字符 | 3.1 |
| 对象内的目录层数 | 相对路径里至多 6 个 `/` | 3.1 |
| 对象内的一条路径 | 80 个字符 | 3.1 |
| 一个对象的文件数 | 2,000 | 3.1 |
| 对象里的一个文件 | 10 MiB | 3.1 |
| 整个对象 | 50 MiB | 3.1 |
| 入口文件 | 256 KiB | 3.2.3 |
| 入口文件的嵌套 | 16 层 | 3.2.3 |
| 入口文件里的整数 | 18 位 | 3.2.3 |
| 入口文件里写出的浮点数 | 32 个字符 | 3.2.3 |
| `lock.json` | 1 MiB | 3.3 |
| 一份说明 | 256 KiB | 4.1 |
| 对象旁边的来源表；删除记录 | 各 1 MiB | 4 |
| 一份时间戳证明 | 64 KiB | 4.3 |
| 删除记录的 `reason` | 1,000 个字符 | 4.2 |
| 删除记录里的来源 | 3 个 | 4.2 |
| 来源表的一行 | 64 KiB | 5.1 |
| 来源表里的 `label`、`license` | 各 256 个字符 | 5.1 |
| 包含行的路径 | 256 个字符 | 5.1 |
| 包含的层数 | 8 层 | 5.1 |
| 一条分组路径 | 1 到 4 段，128 个字符 | 5.1 |
| 一个 `git` 地址 | 512 个字符 | 5.1 |
| 一条 `local` 路径 | 1,024 个字符 | 5.1 |
| 每个对象采用的来源数；发布分支上每条包含行的来源数 | 3 个 | 5.1 |
| 库的清单的一卷 | 16 MiB | 5.2 |
| 对象目录之前的路径 | 60 个字符 | 6.2 |
| 对象名 | 49 个字符 | 6.2 |
| 对象内的路径，连同前面的 `/` | 81 个字符 | 6.2 |
| 库内任何文件的路径 | 190 个字符 | 6.2 |
| 分支名 | 100 个字符 | 6.3 |
| 取一个对象时试的来源数 | 3 个 | 7.3 |
