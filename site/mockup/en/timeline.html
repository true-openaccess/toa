History

Timeline

What of TOA has been made public, the latest first. Dates are in Shanghai time (UTC+8).

  1. 2026-11-25Timestamps left to their owners

    What a stamps directory holds is up to the owner of the object. The tools page suggests OpenTimestamps, and Gazettoa links to that advice for an object without a proof. Learn more

  2. 2026-11-25Monte Carlo records

    The draft standard adds evidence records of the kind mc, for Monte Carlo simulations; Gazettoa shows testbenches and these records.

  3. 2026-11-24Testbenches in the draft standard

    The draft standard says how a testbench measures a circuit: its socket and probes, how a run is assembled, and the targets a circuit can state. The home page shows how to publish the results first and the design later. The use case

  4. 2026-11-24Gazettoa online

    Gazettoa, a read-only web browser of TOA libraries, goes online as a preview, with demo libraries. Open Gazettoa

  5. 2026-11-24Preview published

    The draft standard 0.1, the reference tool toa and this site are published as a preview, with no release yet. The standard is on the site as web pages, Markdown and PDF. Source

  6. 2026-11-23Named TOA

    The format standard for circuit design objects is named TOA, True-OpenAccess, with the GitHub organisation true-openaccess as its home. Organisation
