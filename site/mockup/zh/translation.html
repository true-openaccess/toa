1翻译进度

2发布条件

  • 新语言初始为孵化中，仅建预览页，不进菜单。
  • 导航、首页、Agent 页全译完，其余 ≥ 80% 且经审阅后发布。
  • 不足 80% 显示英文；80%–99% 缺译处回退英文；均以英文提示。

3参与翻译

译文与源码同库，格式与检查见 i18n 目录。

内容路径
标准正文与类型规格spec/0.1/<lang>/, spec/types/<lang>/
术语表i18n/<lang>/glossary.json
网站页面i18n/<lang>/site/<page>.json
共用文案i18n/<lang>/site/messages.json
 
python scripts/i18n/status.py            # 查看进度
python scripts/i18n/status.py files zh   # 单语种文件
python scripts/i18n/status.py check      # 检查格式
